# Sakushi Lab

Sakushi Lab 是一個靜態、多語言的視覺錯覺實驗場。它完全在瀏覽器中執行，使用 Vite、vanilla TypeScript、Canvas、SVG 匯出與 WebM 錄製。

線上站點：[Sakushi Lab](https://piccoripico.github.io/sakushi-lab/)

## 關於視覺錯覺

視覺錯覺是圖像或運動圖案，用來展示知覺會在多大程度上依賴上下文。物理上平行的線可能看起來傾斜，相同大小的形狀可能顯得不同，靜止圖案也可能讓人感覺閃爍或移動。

這些效果並不只是視覺的「錯誤」。它們說明視覺系統會根據周圍資訊估計亮度、對比、深度、方向、大小與運動。Sakushi Lab 可以讓你改變每種錯覺的條件，觀察效果如何變強、變弱或更容易被注意到。

生成的圖像和影片可用於學習、示範、設計實驗與日常探索。一些運動錯覺可能刺激較強；如果動畫讓你不舒服，請休息一下。

## 功能

- 18 種視覺錯覺：
  - 靜止圖像
    - 幾何 / 形狀：
      - 咖啡牆錯覺：錯位的磁磚讓平行線看起來傾斜。
      - 赫爾曼格線：格線交點會產生短暫的暗點。
      - 繆勒-萊爾錯覺：箭羽改變等長線段的感知長度。
      - 龐佐錯覺：透視線索讓相同橫條看起來大小不同。
      - 波根多夫錯覺：遮擋帶讓斜線看起來錯位。
      - 佐爾納錯覺：交叉短線讓平行線看起來傾斜。
      - 黑林錯覺：放射線讓直線平行線看起來向外彎曲。
      - 垂直-水平錯覺：等長的直線與橫線會顯得不等長。
      - 艾賓浩斯錯覺：周圍圓會改變中心圓的感知大小。
      - 德爾布夫錯覺：周圍環會改變相同圓的感知大小。
      - 桑德平行四邊形錯覺：傾斜框架會扭曲線段長度感。
      - 卡尼薩三角形：缺口圓與角形暗示出沒有畫出的三角形。
    - 圖形 / 背景：
      - 魯賓花瓶：花瓶和兩張側臉會在圖形與背景之間競爭。
    - 顏色 / 亮度：
      - 同時對比：相同顏色會因周圍環境而顯得不同。
      - 懷特錯覺：相同灰色條在條紋上看起來不同。
      - 科恩斯威特錯覺：細窄陰影邊界會改變亮度感。
  - 影片
    - 運動 / 後像圖案：
      - 紫丁香追逐者：旋轉缺口會產生移動後像感。
    - 可反轉深度：
      - 旋轉內克爾立方體：運動會突出線框立方體的深度翻轉。
- 根據每個錯覺模組的 schema 生成參數控制。
- 可選的種子控制，用於可重複生成。
- 透過帶種子的 URL 進行確定性生成和分享。
- 匯出 PNG、SVG、WebM 和可復現 URL。
- UI 語言：英語、法語、西班牙語、德語、日語、簡體中文、繁體中文和韓語。

## 開發

```powershell
npm.cmd install
npm.cmd run verify
```

常用腳本：

- `npm.cmd run dev`：啟動 Vite 開發伺服器。
- `npm.cmd test`：執行單元測試。
- `npm.cmd run build`：進行型別檢查並建置 `dist/`。
- `npm.cmd run test:e2e`：執行 Playwright 測試。

## GitHub Pages

`.github/workflows/pages.yml` 中的 workflow 會在推送到 `main` 或手動觸發時建置 `dist/`，並將其作為 Pages artifact 上傳。
